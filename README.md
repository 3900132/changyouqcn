# 畅有趣 · AI 电影视频故事板生成器

> **源码出自：公众号「路上侠客」，由畅有趣调整开源并发布。**

一个免费、开源、纯前端的 AI 分镜创作工具：输入你的故事创意，AI 自动生成完整的故事板——分镜编号、时间码、运镜方式、画面描述、台词、音效和画面 Prompt，并支持批量 AI 生图、生视频与多格式导出。

在线使用：**[https://changyouq.cn/](https://changyouq.cn/)**

---

## ✨ 功能特性

- **AI 生成分镜脚本**：根据故事创意自动展开完整情节，输出结构化分镜（时间码 / 运镜 / 画面描述 / 台词 / 音效 / 画面 Prompt）
- **AI 批量生图**：按分镜 Prompt 批量调用图片模型，支持 2.35:1 / 16:9 / 1:1 / 9:16 画面比例联动硬参数
- **AI 批量生视频**：image-to-video（自动携带首帧图）、多端点探测、任务轮询与实时进度日志
- **多 Key 使用模式**：视频模型支持配置多个 API Key（逗号/分号/换行分隔），两种模式可选：
  - **单线程轮流**：每次请求轮流使用不同 Key（轮询调度），把限流压力分摊到各 Key，适合免费档限流场景
  - **多线程并行**：批量生成时每个 Key 启动一条线程，从共享队列领取分镜同时生成（线程数 = Key 数），成片速度约提升 N 倍
- **成片合成**（导出菜单内）：
  - **▶️ 连播预览**：按分镜顺序在弹层中自动连续播放所有已生成视频，手机/电脑均可用
  - **🎬 合并成片 MP4**：桌面端通过 ffmpeg.wasm 在浏览器内无损拼接为单个 MP4 并下载（首次加载约 25MB 内核，之后走浏览器缓存；纯本地处理，不消耗 API 额度；移动端自动提示改用连播预览）。视频数据优先经同源服务端代理获取（见下方「视频代理函数」），浏览器内全程可视化进度（内核下载进度条 → 分段下载逐段就绪 → 拼接百分比）
  - **📥 导出本地合并脚本**：浏览器内合并因跨域受限时的兜底方案。按操作系统自适应导出（Windows → `.bat`，macOS → `.command`）。Windows 脚本**全自动**：未检测到 ffmpeg 时自动从 npmmirror 阿里云镜像下载单文件版（约 77MB，国内实测 ~6.7MB/s，带实时进度条），下载后直接使用，无需配置环境变量、无需重启窗口；下载/解压/拼接全程进度可视，中文提示正常（UTF-8 BOM）
- **视频代理函数**：内置 EdgeOne Makers 边缘函数（`edge-functions/api/video-proxy.js`），部署后自动生效于 `/api/video-proxy`。服务端中转拉取无 CORS 头的视频直链，使浏览器内合并对访客零安装可用；带域名白名单、500MB 上限、浏览器 UA 头等防滥用/防拦截措施
- **网关自适应**：按 Base URL / 模型名自动识别 Agnes、MiniMax、Seedance 火山方舟等网关协议，请求体按各家字段规范自动构造（如 Agnes Video 2.5 系列使用 `mode/seconds/size/aspect_ratio` 新参数格式，首帧图走 `keyframe` 模式）；网关拒绝某字段时自动剔除重试，触发 429 限流时按 `retry_after` 自动等待重试（最多 3 次）
- **可视化编辑**：网格化分镜卡片，内联/弹窗两种编辑方式，自动持久化
- **多格式导出**：Markdown / JSON 提示词、HTML 故事板、PNG 总图、单镜图片、图片与视频 URL 列表、WebM 预览视频
- **本地演示模式**：未配置模型时使用规则化演示生成，无需 Key 即可体验完整流程
- **实时日志面板**：视频生成全流程请求/响应/轮询日志，便于排查网关兼容问题

## 🚀 快速开始

1. 下载本仓库，直接用浏览器打开 `index.html`（或部署到任意静态托管）
2. 点击右上角设置，配置模型：
   - **文字大模型**：生成分镜脚本（兼容 OpenAI `/chat/completions` 格式）
   - **图片大模型**：生成画面（兼容 `/images/generations` 格式）
   - **视频大模型**：生成视频（兼容 `/videos` 创建 + 轮询格式）；API Key 栏可填**多个 Key**（逗号/分号/换行分隔），并在「使用模式」中选择单线程轮流或多线程并行
   - 填入模型名称、API Key、Base URL，点「保存」并「测试连接」
3. 输入故事创意，选择影片类型/画面比例/时长/风格/色调，点「AI 生成故事板」
4. 逐镜「生图」或直接「批量生图」「批量生视频」
5. 视频生成完成后，通过「导出」菜单使用 **▶️ 连播预览** 或 **🎬 合并成片 MP4**（电脑端）得到完整成片

> 不配置 Key 也可以点击「演示」体验界面和流程（使用本地规则生成，不消耗额度）。

## 🌐 部署说明

- 纯静态文件，任意静态托管（Nginx / OSS / GitHub Pages / Vercel 等）均可
- `robots.txt`、`sitemap.xml`、`llms.txt`、`og-image.png` 需放在站点根目录
- 建议启用 HTTPS 并将域名统一 301 到 `https://changyouq.cn/`（与页面 canonical 一致）
- **EdgeOne Makers 部署**：`edge-functions/` 目录会被自动识别为边缘函数，无需控制台配置；部署后 `/api/video-proxy` 即为视频代理，浏览器内合并成片对访客零安装可用。验证方式：访问 `/api/video-proxy?url=https://api.agnes-ai.cn/test`，返回 JSON（含 403 host not allowed 亦算成功）即函数已生效

## ⚠️ 已知限制与注意事项

1. **CORS 限制**：纯浏览器直连第三方 AI 网关，部分供应商不返回 CORS 响应头会导致请求失败。请使用 CORS 友好的网关（如 OpenAI 官方、常见聚合网关），或在本地/服务端架设反向代理
2. **API Key 安全**：Key 保存在浏览器 localStorage 中（明文）。建议使用限额/专用 Key，不要在公共电脑上保存；本工具不向任何第三方服务器发送你的 Key（全部请求由浏览器直连你填写的网关）
3. **签名 URL 过期**：部分图片/视频 API 返回带签名的临时 URL，过期后需要重新生成；重要素材请及时通过「导出」功能下载保存
4. **长任务**：单个视频生成最长轮询约 20 分钟，批量任务请保持页面在前台（浏览器后台可能暂停定时器）
5. **费用提示**：批量生图/生视频会真实消耗你的 API 额度，请先小规模测试确认网关兼容
6. **合并成片限制**：浏览器内合成 9 段 720P 视频约需 2~3GB 可用内存，低配电脑建议分批操作；移动端仅支持连播预览。视频数据获取按「服务端代理 → 直链 → agnesapi 换取 → 转录」四级回退：部署了 EdgeOne 代理函数时访客零操作；未部署（如本地直接打开 HTML）时若网关视频链接禁止跨域，会引导改用「导出本地合并脚本」
7. **免费档限流**：部分网关（如 Agnes）免费档有每分钟请求数/总量限制，触发 429 时页面会自动倒计时重试（最多 3 次）；配额耗尽（而非速率限制）时只能等待刷新或升级套餐。多 Key + 多线程并行可有效提高批量吞吐
8. **本地合并脚本**：Windows 脚本未检测到 ffmpeg 时会自动从 npmmirror 阿里云镜像下载单文件版（约 77MB，保存在脚本同目录，可重复使用）；下载与拼接全程带进度条与中文提示。macOS/Linux 脚本需自行安装 ffmpeg（教程见页面「使用说明」）
